# Backend scaffold

Backend folders are created for the project-structure milestone. Server logic is intentionally not implemented yet.

- `config/` — future environment and database configuration
- `dao/` — future data-access objects / database queries
- `middleware/` — future authentication and error-handling middleware
- `routes/` — future API route definitions
- `services/` — future business logic and external API integration

Do not commit secrets or API keys. Use environment variables in a later milestone.
